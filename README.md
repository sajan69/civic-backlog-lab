# Civic Backlog Lab

A Python/SQL project for analysing public service-request backlogs, closure times and data quality.

The focus is on comparing completed requests with the work that remains open, using explicit observation windows and reproducible data snapshots. Administrative closure does not necessarily mean a reported problem was resolved.

The initial data source is [NYC 311 Service Requests](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9/about_data). [NYC's reporting guide](https://www.nyc.gov/site/311reporting/311-reports/service-requests.page) explains the service-request context.

No runnable implementation is published yet.
